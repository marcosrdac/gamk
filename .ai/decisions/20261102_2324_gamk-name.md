# Decision: name the project GAMK — Git Agent Memory Kit

- **Status:** Confirmed by the user in conversation on 2026-11-02.
- **Originating work:** `010_20261102_2319_rename-project-to-gamk`.
- **Branch/worktree:** `feat/gamk-rename` / `.git-worktrees/gamk-rename`.

## Decision

The public project name is **GAMK — Git Agent Memory Kit**. New source and consumer manifests use `gamk-source`, `gamk-consumer`, and `gamk` as their machine-readable identifiers.

The previous `git-ai-global-source`, `git-ai-global-consumer`, and `git-ai-global` identifiers remain readable for compatibility with existing installations. New files and documentation use GAMK. The physical repository path, `.ai/` layout, `global/` directory, installer script names, `.ai/global-manifest.json`, and `.git-worktrees/` convention remain stable.

## Rationale

“Agent Memory” describes the project's durable instructions, decisions, rules, skills, workflows, and context more accurately than “AI Memory”. “GAMK” is short while the expanded name explains the purpose. Preserving operational paths avoids breaking local links and consumer workflows merely because the public identity changed.

## Consequences

The README and current documentation present GAMK as the product. Legacy technical identifiers may still appear in compatibility code and historical records; they are not the current public identity.
